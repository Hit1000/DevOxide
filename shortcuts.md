# Dev Oxide Shortcuts

Here is a list of all the keyboard shortcuts available in Dev Oxide to improve your productivity:

## Global Shortcuts
These shortcuts work from anywhere within the application.

| Shortcut | Action |
| --- | --- |
| `Ctrl + K` (or `Cmd + K`) | Open the Command Palette / Quick Tool Switcher (Coming soon) |
| `Ctrl + +` (or `Ctrl + =`) | Increase the global text size |
| `Ctrl + -` | Decrease the global text size |
| `Alt + \`` | Toggle between Light and Dark theme |

## Tool-Specific Shortcuts

### Diff Tool
| Shortcut | Action |
| --- | --- |
| `Ctrl + S` | Save current comparison state (if applicable) |

### JSON Formatter
| Shortcut | Action |
| --- | --- |
| `Ctrl + Enter` (or `Cmd + Enter`) | Format & Repair the JSON input immediately |

*Note: On macOS, `Cmd` is used in place of `Ctrl`.*
